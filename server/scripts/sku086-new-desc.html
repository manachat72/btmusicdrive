USB แฟลชไดรฟ์ MP3 เพลงเพื่อชีวิต คาราบาว 4GB รวม 325 เพลง ครบทุกอัลบั้ม

รวมเพลงคาราบาว MP3 ครบทุกอัลบั้ม 325 เพลง
ไฟล์ MP3 คุณภาพสูง 320kbps เสียงคมชัดเต็มอิ่ม
ความจุ USB 4GB ของแท้ ทนทาน อ่านไฟล์ไว
เสียบฟังในรถยนต์, ลำโพง, คอมพิวเตอร์, ทีวี ได้เลย ไม่ต้องต่อเน็ต
เหมาะเป็นของขวัญให้คนรักเพลงเพื่อชีวิต ผู้ใหญ่ หรือคุณพ่อ

เพลงฮิตเช่น: เมดอินไทยแลนด์ / ทะเลใจ / บัวลอย / คนล่าฝัน / มนต์เพลงคาราบาว และอีกมากมาย
ทางร้านตรวจสอบไฟล์และทดสอบแฟลชไดร์ฟก่อนจัดส่งทุกชิ้น

รับประกัน 7 วัน เสียจากการผลิตเปลี่ยนใหม่ฟรี · ส่งฟรีเมื่อสั่งครบ 200 บาท · เก็บเงินปลายทางได้
