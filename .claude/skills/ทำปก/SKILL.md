# ทำปก — พรอมรูปปก + hook จาก SKU (หลบลิขสิทธิ์)

รับ SKU → **ค้นสินค้าจริง → สกัดธีม → ออกพรอม 3 ตัวเลือก + NEGATIVE เต็ม → คิด hook บนปก**
คู่กับ skill `usb-mp3-gpt-image-cover` (เจนภาพจริง) และ `docs/cover-prompts-safe.md` (กฎเต็ม)

---

## ขั้นที่ 1 — ค้นสินค้าจาก SKU (ห้ามข้าม)

```bash
node -e "const a=require('./products.json');const p=a.find(x=>x.sku==='<SKU>');if(!p){console.log('NOT_FOUND');process.exit(0)}console.log(JSON.stringify({name:p.name,slug:p.slug,cat:p.category&&p.category.name,tags:p.tags,n:(p.tracklist||[]).length,sample:(p.tracklist||[]).slice(0,15)},null,1))"
```

- `NOT_FOUND` → ลองค้นแบบหลวม (`x.sku.includes(...)` หรือ grep ชื่อ) ถ้ายังไม่เจอ ให้ถามผู้ใช้ว่าสินค้าตัวไหน **ห้ามเดา**
- ผู้ใช้ส่งชื่อสินค้า/แนวเพลงแทน SKU ก็ได้ → ข้ามไปขั้น 2 โดยใช้ข้อความนั้นเป็นธีม

## ขั้นที่ 2 — สกัดธีม (สำคัญที่สุด)

เรียงตามความน่าเชื่อถือ:

1. **`name` + `tags` = แหล่งธีมหลัก** — ชื่อศิลปิน/วง/แนว/ภูมิภาคอยู่ตรงนี้
   ตัวอย่างจริง `BT-PC-01-053` → name "รวมเพลงมาลีฮวนน่า 82 เพลง 1GB" · tags มี `เพลงมาลีฮวนน่า`, `เพลงเพื่อชีวิตแดนใต้`, `สหายสุรา มาลีฮวนน่า` → ธีม = **มาลีฮวนน่า / เพื่อชีวิตแดนใต้**
2. **`tracklist`** — ใช้ดู "เพลงดัง/เพลงเปิดตัว" และจำนวนเพลง
   ⚠ **ห้าม parse ชื่อศิลปินจากเครื่องหมายขีดใน tracklist** — ชื่อเพลงไทยมีขีดเองได้ (เช่น `ลมเพ-ลมพัด`)
   แยกศิลปินได้เฉพาะเมื่อรูปแบบชัดจริง ๆ เช่น `001. ชื่อเพลง - ชื่อศิลปิน` ทั้งไฟล์
3. **`scripts/data/artists.json`** — ถ้ามี entry ของศิลปินนั้น อ่านเอา `genre/keywords/hook/notes` มาใช้ได้เลย (ไม่ต้องเสิร์ช)
4. **WebSearch** — ใช้ต่อเมื่อยังไม่รู้จักศิลปิน/ธีม ค้นสั้น ๆ ว่า *วงอะไร แนวไหน ภูมิภาคไหน ยุคไหน สัญลักษณ์ประจำวงคืออะไร เพลงดังคือเพลงอะไร*
   — เอาไปใช้แค่เป็น **วัตถุดิบภาพ** ห้ามเอาไปเขียนชื่อสินค้า/description (นั่นเป็นงาน `buildSeo()`)

สรุปเป็น 4 บรรทัดก่อนออกพรอม: **ศิลปิน/ธีม · แนว+ภูมิภาค · ยุค · เพลงดัง 3–5 เพลง**

## ขั้นที่ 3 — ทำยังไงให้ "เห็นแล้วรู้ว่าเป็นเขา" โดยไม่ละเมิด

**กฎแกน: จำได้จาก "โลกของเขา" ไม่ใช่ "ตัวเขา"**

| ใช้ได้ (แฟนจำได้) | ห้ามเด็ดขาด |
|---|---|
| **ภูมิภาค/ฉากประจำวง** เช่น มาลีฮวนน่า→ทะเลใต้/เรือ/หาด · คาราวาน→ป่าเขา/กองไฟ | ใบหน้าเหมือนศิลปินจริง |
| **เครื่องดนตรีเอกลักษณ์** (unbranded) เช่น กีตาร์โปร่ง, ซออู้, แคน, ขลุ่ย | โลโก้วง / ฟอนต์โลโก้ / ลายเซ็น |
| **ยุค/พื้นผิว** เกรนฟิล์ม, สีซีดยุค 90, ฟิล์มสไลด์ | ลอกองค์ประกอบปกอัลบั้มจริง |
| **พร็อพประจำตัวแบบทั่วไป** หมวกปีก, ผ้าขาวม้า, ย่าม | ตราค่ายเพลง / คำว่า official |
| **พาเลตประจำอารมณ์วง** | เงาที่จงใจให้เหมือน "คนคนนั้น" เป๊ะ |

→ คนเป็น **เงา/หันหลัง/ไม่เห็นหน้า** เสมอ และเป็น "คนทั่วไปในโลกนั้น" ไม่ใช่ตัวศิลปิน
→ ถ้าผู้ใช้ขอ "ทำให้เหมือนเขาเลย / ใส่หน้าเขา / สไตล์ปกอัลบั้มเขา" → **ปฏิเสธ** อธิบายสั้น ๆ แล้วเสนอทางโลก/บรรยากาศแทน

## ขั้นที่ 4 — ประกอบพรอม 3 ตัวเลือก

**สูตร:** ฉากจากคลังของหมวด (ล่าง) **+ overlay ธีม** จากขั้น 2–3 (ภูมิภาค/ยุค/สัญลักษณ์/พาเลต)
เช่น PC + ธีมแดนใต้(มาลีฮวนน่า) → ฉาก PC ที่ย้ายบริบทไปริมทะเล/ท่าเรือใต้

เลือก 3 ฉาก **ไม่ซ้ำกัน**: เริ่ม index = `เลขชุดท้าย SKU mod จำนวนฉาก` แล้วหยิบต่อเนื่อง
(SKU เดิม = ผลเดิมคงที่ · SKU ต่างกัน = ฉากต่างกัน · พิมพ์ "อีกชุด" = ขยับ +3)

### พาเลตตามหมวด
`PC` เพื่อชีวิต น้ำตาลไหม้-ส้มพระอาทิตย์-เทาควัน · `LT` ลูกทุ่ง ทอง-ชมพู-เขียวข้าว · `ST` สตริง/ร็อค ถ่าน-ส้มอำพัน-แดงเลือดหมู · `LK` ลูกกรุง ครีม-ทองซีด-แดงไวน์ · `TA` ใต้ ฟ้าเทอร์ควอยซ์-ส้มอาทิตย์-ขาวทราย · `IN` สากล น้ำเงินเข้ม-เงิน-ขาวนวล · `DZ` แดนซ์ นีออนแมเจนตา-ไซแอน-ม่วง · `DM` ธรรมะ ทองอ่อน-น้ำตาลไม้-ขาวนวล · `RD` วิทยุ น้ำตาล-ครีม-ทองเหลือง · `AC` อุปกรณ์เสริม เทา-เงิน-ส้มอำพันจุดเดียว

### คลังฉาก (ทุกชิ้น unbranded · คนเป็นเงาไม่เห็นหน้า)

**PC เพื่อชีวิต** — 1) ถนนลูกรังยามเย็น เงาชายสะพายกีตาร์เดินหันหลังหาแดด ฝุ่นฟุ้ง · 2) เวทีไม้เล็กกลางแจ้งค่ำ กีตาร์พาดเก้าอี้ หมวกปีกบนแอมป์ผ้าเก่า ไฟหลอดไส้แขวนสายเดียว · 3) กีตาร์โปร่งพิงกำแพงปูนเปลือย แดดบ่ายเงายาว ใบไม้ร่วง · 4) ร้านเหล้าต่างจังหวัดดึก โต๊ะไม้ ขวดสังกะสี กีตาร์วางพิง นีออนแดงจาง · 5) ท้ายกระบะรถเก่าจอดริมทุ่ง กีตาร์+ผ้าขาวม้า ฟ้าพลบค่ำ · 6) ริมทางรถไฟเช้ามืด รางทอดไกล เงาคนแบกกีตาร์เดิน หมอกบาง

**LT ลูกทุ่ง** — 1) ทุ่งนาเย็น พวงมาลัยดาวเรือง ไมค์โบราณขาตั้งเหล็ก ผ้าซาตินชมพูพลิ้ว · 2) งานวัดกลางคืน ไฟประดับสีทอง เวทีลูกทุ่งเล็ก ริบบิ้นทอง · 3) เกวียนไม้+กองฟาง ฟ้าทอง มาลัยดอกรัก · 4) ระเบียงบ้านไม้ไทย แจกันดอกไม้ ไมค์วินเทจ ม่านลูกไม้ แดดสาย · 5) ตลาดน้ำเช้า เรือ+ดอกไม้ แสงทองสะท้อนน้ำ · 6) เวทีหมอลำอีสาน แคน+พิณบนเสื่อ ผ้าไหมมัดหมี่ โทนทองแดง

**ST สตริง/ร็อค** — 1) ห้องซ้อมมืด ปิ๊ก+ตู้แอมป์ตะแกรงเปล่า สายแจ็คขด ลำแสงส้มแดงเฉียง · 2) ตรอกเมืองกลางคืน กำแพงกราฟฟิตี้นามธรรม ไฟนีออน กีตาร์ไฟฟ้าพิง · 3) เวทีคอนเสิร์ตมืด สปอตไลต์เจาะ ควันเวที เงาไมค์สแตนด์ · 4) ดาดฟ้าตึกกลางคืน ไฟเมืองเบลอ กีตาร์ไฟฟ้า โทนน้ำเงิน-ส้ม · 5) โรงรถเก่า เครื่องขยายกองซ้อน โปสเตอร์ฉีกนามธรรม หลอดไฟกระพริบ · 6) สตูดิโอไฟสลัว ไมค์+หูฟัง แผงมิกเซอร์เบลอ

**LK ลูกกรุง** — 1) เครื่องเล่นแผ่นเสียงไม่มีฉลาก ม่านกำมะหยี่ไวน์ กุหลาบขาว แสงหน้าต่างนุ่ม · 2) คาเฟ่ยุคเก่า โต๊ะไม้ขัดเงา ถ้วยกาแฟ เปียโนหลังเบลอ · 3) ห้องนั่งเล่นวินเทจ โซฟากำมะหยี่ วิทยุไม้ โคมไฟผ้า · 4) เวทีเลานจ์ ไมค์วินเทจ ไฟสปอตนวล ม่านซาติน · 5) โต๊ะเครื่องแป้งเก่า กระจก ดอกไม้ ขวดน้ำหอมแก้ว

**TA เพลงใต้** — 1) ท่าเรือประมงเช้า เรือหัวโทงสีสด ทะเลเรียบสะท้อนแสงส้ม ฉิ่ง+กลองบนเสื่อ · 2) หาดทรายเย็น เรือกอและ แสงทอง เงามะพร้าว · 3) เลพลบค่ำ ท่าเทียบเรือไม้ ตะเกียง · 4) ตลาดปลาริมทะเล ตะกร้า เรือสีสด แดดเช้า · 5) เครื่องดนตรีพื้นบ้านใต้บนเสื่อริมทะเล ผ้าสีสด

**IN สากล** — 1) สตูดิโอวินเทจ ไมค์คอนเดนเซอร์ในกรอบกันสะเทือน หูฟังบนขาตั้ง · 2) คลับแจ๊สมืด แซกโซโฟนเงา ไฟสปอตนวล ควันบาง · 3) แผ่นไวนิลกองบนโต๊ะไม้ เครื่องเล่นไม่มีฉลาก · 4) เมืองกลางคืนเบลอ โบเก้ไฟ หูฟังหน้ากล้อง · 5) ห้องอัดมินิมอล ไมค์+โน้ตเพลง แสงขาวนวล

**DZ แดนซ์** — 1) ฟลอร์นามธรรม เลเซอร์ชมพู-ฟ้า-ม่วง ละอองหมอก คลื่นเสียงเรืองแสง · 2) เงาคนเต้นไกล ๆ ไฟสโตรบ · 3) ลำโพงกองใหญ่เงา ไฟเวทีพุ่ง ควัน · 4) อุโมงค์แสงนีออน เส้นแสงวิ่ง · 5) หยดสีนีออนบนพื้นดำมันวาว

**DM ธรรมะ** — 1) ศาลาไม้เช้า บาตรบนผ้าเหลืองพับ ดอกบัวในขัน ควันธูปบาง · 2) ใต้ต้นโพธิ์ ใบไม้ร่วง แสงลอด · 3) ริมสระบัวเช้า ดอกบัวตูม หมอกบาง · 4) โต๊ะหมู่บูชาเรียบง่าย เทียน ดอกไม้ ธูป (ไม่มีพระพุทธรูปที่จำได้) · 5) ทางเดินวัดเช้า พื้นหิน แสงเฉียง

**RD วิทยุ** — 1) วิทยุทรานซิสเตอร์เก่าหน้าปัดเปล่า เสาอากาศยืด สายไฟถัก แสงอุ่น · 2) โต๊ะไม้เก่า วิทยุ+แก้วกาแฟ แดดเช้าเงายาว · 3) ชั้นไม้เก่า วิทยุหลอด ของสะสมยุค · 4) หน้าต่างบ้านไม้ วิทยุตั้งขอบ ม่านลูกไม้

**AC อุปกรณ์เสริม** — 1) แฟลชไดรฟ์โลหะเปล่า+สายคล้อง พื้นเทาไล่เฉด แสงซอฟต์บ็อกซ์ · 2) ไดรฟ์บนไม้ ข้างต้นไม้เล็ก แสงข้าง · 3) กล่องสินค้า+ไดรฟ์ พื้นขาว เงานุ่ม · 4) ไดรฟ์+หูฟัง พื้นเทา แสงจุดเดียวส้ม

### โครงพรอม (ต่อ NEGATIVE เต็มทุกตัว — ห้ามย่อ)

```
ปกสินค้าแฟลชไดรฟ์รวมเพลง<แนว> — <ฉาก + overlay ธีม>, โทน<พาเลต>, ภาพถ่าย/โปสเตอร์คุณภาพสูง อบอุ่นสมจริง, จัดวาง: subject กลางค่อนบน, ล่างหนึ่งในสามเป็นพื้นมืดเรียบว่าง, มุมบนสองข้างโปร่ง, ไม่มีตัวหนังสือในภาพ, 1:1
NEGATIVE: no real person's face, no celebrity likeness, no recognizable album cover, no band logos, no brand names, no headstock logo, no trademarks, no readable text of any language, no watermark, no signature, no record label mark, no cartoon characters, no busy detail in the bottom third, no clutter in the top-left and top-right corners
```

## ขั้นที่ 5 — คิดหัวเรื่อง / hook บนปก (3–5 ตัวเลือก)

ใช้ข้อมูลจริงจากขั้น 1–2: จำนวนเพลง, ความจุ, ธีม, เพลงดัง

**โครงที่ใช้ได้ผล:** `<หัวใหญ่ 2–4 คำ>` + `<บรรทัดรอง: ธีม/ศิลปิน>` + `<ตัวเลข: N เพลง>`
ตัวอย่างโครง — "รวมสุดยอดเพลงเพื่อชีวิต" / "ตำนานเพื่อชีวิตแดนใต้" / "ฟังยาว ๆ ไม่ต้องใช้เน็ต"

**กฎ hook:**
- ✅ ใส่ชื่อศิลปิน/วงได้ (ข้อเท็จจริงว่าในไดรฟ์มีเพลงใคร) — แต่เป็นตัวอักษรธรรมดา ห้ามทำเป็นโลโก้/ลายเซ็น
- ✅ ตัวเลขจริงเท่านั้น (จำนวนเพลงจาก tracklist, ความจุจาก SKU)
- ❌ ห้าม `official`, `ลิขสิทธิ์แท้`, `จัดจำหน่ายโดย…`, `ของแท้ 100%`, `ถูกที่สุด`, `อันดับ 1`
- ❌ ห้ามอ้าง "ครบทุกอัลบั้ม" ถ้าไม่ได้ครบจริง (โฆษณาเกินจริง)
- ข้อความบนปก **render ผ่าน template ร้าน (PIL) ไม่ใช่ให้ AI เขียนในภาพ**

## ขั้นที่ 6 — ชื่อสินค้า 3 ชื่อ + รายละเอียด + แท็ก

⚠ **ห้ามแต่งชื่อ/รายละเอียด/แท็กเอง** — ต้องยิงเข้า `buildSeo()` เสมอ เพราะมันคุมความยาวชื่อ ≤120,
meta 155 ตัว, slug, tags เพดาน 12–14 และ `validateSeo()` เช็กชื่อ/slug ซ้ำ
**งานของ skill คือคิด `shortName` 3 มุม แล้วให้เครื่องยนต์ปั่นที่เหลือ**

**ความจุจาก SKU** (เลขกลุ่มที่ 3): `01`=1GB `02`=2GB `04`=4GB `08`=8GB `16`=16GB `32`=32GB `M5`=512MB `00`=ไม่ระบุ

**3 มุมของ shortName** (สั้น เป็นคำค้นจริง ไม่ใช่ประโยค):
1. **ศิลปิน/ธีมล้วน** — เช่น `มาลีฮวนน่า` (คำค้นตรงที่สุด)
2. **ศิลปิน + แนว/ภูมิภาค** — เช่น `มาลีฮวนน่า เพื่อชีวิตแดนใต้` (จับ long-tail)
3. **แนว/ภูมิภาค + ศิลปิน** หรือมุมยุค/จุดขาย — เช่น `เพื่อชีวิตแดนใต้ มาลีฮวนน่า`, `เพื่อชีวิตยุค 90`

**รันจริง:**
```bash
node -e "
const {buildSeo,validateSeo}=require('./scripts/lib/seo.js');
const all=require('./products.json');
const p=all.find(x=>x.sku==='<SKU>');
const shorts=['<มุม1>','<มุม2>','<มุม3>'];
shorts.forEach((s,i)=>{
  const r=buildSeo({shortName:s,tracklist:p.tracklist,capacity:'<CAP>',price:279,categoryName:p.category.name});
  const v=validateSeo(r,all);
  console.log('---',i+1,'|',s,'---');
  console.log('name:',r.name,'('+r.name.length+')');
  console.log('slug:',r.slug);
  console.log('meta:',r.metaDescription);
  console.log('tags:',r.tags.join(', '));
  console.log('desc:',r.description);
  console.log('missing:',JSON.stringify(r.artistsMissing));
  console.log('validate:',v.length?JSON.stringify(v):'ผ่าน');
});
"
```

**อ่านผลแล้วรายงาน:**
- ตัวไหน `validate` ขึ้น `error` (ชื่อ/slug ซ้ำ) → บอกว่าใช้ไม่ได้ ให้เลี่ยง
- `artistsMissing` ไม่ว่าง **หรือ** tags ไม่มีคีย์เวิร์ดชื่อศิลปินเลย ทั้งที่ธีมชัดว่าเป็นศิลปินคนนั้น
  → เตือนว่าให้รัน agent `seo-artist-research` ก่อน แล้ว `buildSeo()` จะเติม long-tail รายศิลปินให้เอง
  (เกิดบ่อยเมื่อ tracklist เป็นชื่อเพลงล้วน ไม่มี `- ศิลปิน` ต่อท้าย — `extractArtists()` ดึงไม่ได้)
- **ห้ามแก้ผลลัพธ์ของ buildSeo ด้วยมือ** ถ้าอยากได้ผลต่าง ให้เปลี่ยน `shortName` แล้วรันใหม่

## ขั้นที่ 7 — เจนรูปจริง (ปิดงานด้วยรูป ไม่ใช่แค่พรอม)

**skill นี้ต้องส่งมอบ "รูป" ไม่ใช่หยุดที่พรอม** เจนด้วยเครื่องมือถาวรในโปรเจกต์:

```bash
python scripts/gen-cover-images.py <spec.json>
```

`spec.json` (เขียนลง scratchpad ไม่ใช่ใน repo):
```json
{"sku":"BT-PC-04-040","scenes":{"A-pickup-field":"<พรอมฉาก A>","B-railway-dawn":"<พรอม B>","C-dirt-road-dusk":"<พรอม C>"}}
```

- **ไม่ต้องใส่ NEGATIVE ใน scenes** — สคริปต์ต่อให้เอง (ชุดเดียวกับขั้นที่ 4)
- key ของ scene = ชื่อสั้นภาษาอังกฤษสื่อฉาก → ได้ไฟล์ `cover-output/<SKU>-<key>.png` 1024×1024
- โมเดล `gpt-image-2` → fallback `gpt-image-1` · ต้องมี env `OPENAI_API_KEY`
  **ไม่มี key → แจ้งผู้ใช้ให้ตั้งค่าเอง ห้ามขอ key มาแปะในแชต**
- ใช้เวลาต่อรูปพอสมควร → **รัน background** แล้วรายงานผลเมื่อเสร็จ
- เจน 3 รูปมีค่าใช้จ่าย API — ถ้าผู้ใช้อยากประหยัด เสนอเจนตัวเดียวก่อนได้

**ตรวจรูปด้วยตาทุกใบก่อนส่งมอบ** (`Read` ไฟล์ภาพ) เช็ก:
ตัวหนังสือ/โลโก้มั่วที่ AI แถมมา · ใบหน้าคนจริง · ตราสัญลักษณ์คล้ายโลโก้วง ·
ล่าง 1/3 ต้องมืดเรียบพอให้แถบโลโก้ทับ · มุมบนสองข้างต้องโล่ง
→ ใบไหนไม่ผ่าน บอกผู้ใช้แล้วเสนอเจนใหม่ **ห้ามส่งใบที่เพี้ยน**
→ ส่งไฟล์ให้ผู้ใช้ดูด้วย `SendUserFile`

## รูปแบบคำตอบ

1. บรรทัดสรุปสินค้า: SKU · ชื่อ · หมวด · จำนวนเพลง · ความจุ
2. สรุปธีม 4 บรรทัด (ศิลปิน/ธีม · แนว+ภูมิภาค · ยุค · เพลงดัง)
3. พรอม A/B/C (แต่ละตัวมี NEGATIVE เต็ม)
4. hook 3–5 ตัวเลือก (แยกชุดมีชื่อศิลปิน / ไม่มีชื่อ)
5. **ชื่อสินค้า 3 ตัวเลือกจาก `buildSeo()`** พร้อม slug + meta + tags + สถานะ validate
6. **รูปจริง** — เจนแล้วตรวจด้วยตา แล้วส่งไฟล์ให้ผู้ใช้

**ไม่ต้อง commit ไม่เขียน DB** — รูปไปอยู่ `cover-output/` ส่วนข้อความให้ผู้ใช้ตรวจแล้ววางใน Product Studio เอง
(ข้อความบนปกใส่ทีหลังผ่าน template ร้าน/PIL — ไม่ให้ AI เขียนตัวหนังสือในภาพ)
