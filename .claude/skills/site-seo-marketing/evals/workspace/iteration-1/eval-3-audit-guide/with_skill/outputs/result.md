# คู่มือ SEO เบื้องต้นสำหรับหน้าสินค้าร้านขาย USB เพลงออนไลน์

> อ้างอิงจาก: skill `site-seo-marketing` | วันที่: 2026-05-24

---

## 1. องค์ประกอบ SEO ที่หน้าสินค้าควรมี

ตามเกณฑ์ on-page audit ของ skill นี้ หน้าสินค้าทุกหน้าควรมีองค์ประกอบดังต่อไปนี้ครบถ้วน:

### 1.1 องค์ประกอบ Meta & Title

| องค์ประกอบ | เกณฑ์ที่ดี | ตัวอย่างสำหรับ USB เพลง |
|-----------|-----------|------------------------|
| `<title>` | 50–60 ตัวอักษร, มีคีย์เวิร์ดหลักนำหน้า, มีชื่อแบรนด์ท้าย | `USB เพลงลูกทุ่ง 500 เพลง ฟังในรถไม่ต้องเน็ต | btmusicdrive` |
| `<meta description>` | 150–160 ตัวอักษร, มีคีย์เวิร์ด, มี CTA | `USB เพลงพร้อมฟัง 500 เพลงเพราะ ใช้ได้ในรถ คอม เครื่องเสียง ไม่ต้องต่ออินเทอร์เน็ต สั่งได้วันนี้ ส่งไวทั่วไทย` |
| `<h1>` | มีเพียง 1 ตัวต่อหน้า, มีคีย์เวิร์ดหลัก, เน้น benefit | `USB เพลงพร้อมฟัง 500 เพลงเพราะ — ฟังได้ทุกที่ ไม่ต้องเน็ต` |

### 1.2 โครงสร้างหน้าสินค้า

- **H2/H3 ที่มีโครงสร้างชัดเจน** — เช่น "รายละเอียดสินค้า", "จุดเด่นที่คุ้มค่า", "วิธีใช้งาน", "คำถามที่พบบ่อย"
- **ไม่ข้าม heading level** — ห้ามกระโดดจาก H1 ไป H3 โดยไม่มี H2
- **URL ที่เป็นมิตรกับ SEO** — สั้น, มีคีย์เวิร์ด, ไม่มีตัวเลขสุ่ม
  - ดี: `/products/usb-pleng-luktung-500`
  - ไม่ดี: `/products/item?id=8472&cat=3`

### 1.3 รูปภาพสินค้า

- **Alt text ทุกรูป** — ระบุว่าภาพแสดงอะไร พร้อมคีย์เวิร์ด เช่น `alt="USB เพลงลูกทุ่งสำเร็จรูป 500 เพลง แพ็กเกจสีส้ม"`
- **ขนาดไฟล์รูปที่เหมาะสม** — compress รูปก่อนอัปโหลด (แนะนำ WebP หรือ JPEG ที่ปรับแล้ว)
- **ตั้งชื่อไฟล์รูปให้มีคีย์เวิร์ด** — เช่น `usb-pleng-luktung-500-songs.jpg` ไม่ใช่ `IMG_00234.jpg`

### 1.4 Internal Links

- **ลิงก์เชื่อมสินค้าที่เกี่ยวข้อง** — เช่น จากหน้า USB เพลงลูกทุ่ง ลิงก์ไปหน้า USB เพลงอีสาน, USB เพลงใต้
- **Anchor text ที่มีคีย์เวิร์ด** — เช่น "ดู USB เพลงผสมหลายแนว" ไม่ใช่ "คลิกที่นี่"
- **ลิงก์ไปหน้า Category** — เพื่อกระจาย link equity

### 1.5 Schema Markup (Structured Data)

- **Product Schema** — ระบุชื่อสินค้า, ราคา, สต็อก, รีวิว/rating เพื่อให้ Google แสดง rich snippet
- **BreadcrumbList Schema** — แสดงเส้นทาง เช่น หน้าหลัก > USB เพลงลูกทุ่ง > USB เพลงลูกทุ่ง 500 เพลง

ตัวอย่าง Product Schema เบื้องต้น:
```json
{
  "@context": "https://schema.org/",
  "@type": "Product",
  "name": "USB เพลงลูกทุ่ง 500 เพลงพร้อมฟัง",
  "description": "USB MP3 เพลงลูกทุ่ง 500 เพลงเพราะ ฟังได้ไม่ต้องเน็ต ใช้ได้ในรถ คอม เครื่องเสียง",
  "offers": {
    "@type": "Offer",
    "priceCurrency": "THB",
    "price": "149",
    "availability": "https://schema.org/InStock"
  }
}
```

### 1.6 ความเร็วและ Technical

- **ไม่มี render-blocking scripts** — ย้าย JavaScript ไปท้ายหน้า หรือใช้ `defer/async`
- **Core Web Vitals ผ่านเกณฑ์** — LCP < 2.5 วิ, FID < 100ms, CLS < 0.1
- **Mobile-friendly** — หน้าแสดงผลถูกต้องบนมือถือ เพราะกลุ่มเป้าหมายส่วนใหญ่ซื้อผ่านมือถือ

## 2. คีย์เวิร์ดสำคัญที่ควรใช้ในหน้าสินค้า

อ้างอิงจาก `references/thai-keywords.md`:

### Head Keywords (ใช้ใน Title / H1)
| คีย์เวิร์ด | Intent | เหมาะกับหน้าไหน |
|-----------|--------|----------------|
| USB เพลงสำเร็จรูป | Transactional | Homepage / Category |
| USB เพลงในรถ | Transactional | Category + สินค้า |
| แฟลชไดร์ฟเพลง | Transactional | Category |

| USB เพลงพร้อมฟัง | Transactional | Homepage |

### Long-tail Keywords (ใช้ใน Description / เนื้อหา)
| คีย์เวิร์ด | เหมาะกับสินค้า |
|-----------|---------------|
| USB เพลงลูกทุ่ง 500 เพลง ฟังในรถ | USB เพลงลูกทุ่ง |

## 3. ปัญหา SEO ที่พบบ่อยสำหรับร้านขาย USB เพลง พร้อมวิธีแก้

### ปัญหาที่ 1 — Title tag ซ้ำหรือไม่มีคีย์เวิร์ด

**อาการ:** Title tag เหมือนกันทุกหน้าสินค้า เช่น "สินค้า | ร้านเรา" หรือใช้แค่ชื่อสินค้าโดยไม่มี context

**ผลกระทบ:** Google ไม่รู้ว่าหน้านี้เกี่ยวกับอะไร ทำให้ไม่ติดอันดับสำหรับคีย์เวิร์ดเป้าหมาย

**วิธีแก้:**
- เขียน Title tag เฉพาะทุกหน้า ขึ้นต้นด้วยคีย์เวิร์ดหลัก
- รูปแบบ: `[คีย์เวิร์ดหลัก] [จำนวนเพลง] [จุดขาย] | [ชื่อแบรนด์]`
- ตัวอย่าง: `USB เพลงลูกทุ่ง 500 เพลง ฟังในรถไม่ต้องเน็ต | btmusicdrive`

---

### ปัญหาที่ 2 — Meta description ขาดหายหรือซ้ำกัน

**อาการ:** ไม่ได้ตั้ง meta description หรือทุกหน้าใช้ข้อความเดียวกัน

**ผลกระทบ:** Google ดึง snippet อัตโนมัติที่ไม่ดึงดูด → CTR ต่ำ → traffic น้อย

**วิธีแก้:**
- เขียน meta description แต่ละหน้าให้ไม่ซ้ำกัน ความยาว 150–160 ตัวอักษร
- ต้องมี: คีย์เวิร์ด + benefit หลัก + CTA ("สั่งได้วันนี้", "ส่งไว", "ดูสินค้า")

---

### ปัญหาที่ 3 — ชื่อรูปภาพและ Alt text ว่างเปล่า

**อาการ:** ไฟล์รูปชื่อ `IMG_1234.jpg` และ alt text เป็น `""` หรือ `"-"`

**ผลกระทบ:** Google Image Search ไม่สามารถ index ได้ ทำให้เสียโอกาส traffic จาก image search และ accessibility score ต่ำ

**วิธีแก้:**
- ตั้งชื่อไฟล์รูปด้วยคีย์เวิร์ด เช่น `usb-pleng-luktung-500-songs.jpg`
- ใส่ alt text ทุกรูปที่บรรยายสิ่งที่เห็น เช่น `alt="USB เพลงลูกทุ่ง 500 เพลง สำหรับเปิดในรถ"`

---

### ปัญหาที่ 4 — URL ไม่เป็นมิตรกับ SEO

**อาการ:** URL เป็น `/products?id=4512` หรือ `/p/8472xz`

**ผลกระทบ:** Google และผู้ใช้ไม่รู้ว่าหน้านี้ขายอะไร ส่งผลต่อ CTR และ ranking

**วิธีแก้:**
- ปรับ URL ให้มีคีย์เวิร์ด สั้น อ่านได้
- ตัวอย่าง: `/products/usb-pleng-luktung-500`
- ถ้าต้องเปลี่ยน URL เดิม ให้ทำ 301 redirect เสมอ

---

### ปัญหาที่ 5 — ไม่มี Schema Markup (Structured Data)

**อาการ:** หน้าสินค้าแสดงใน Google แบบธรรมดา ไม่มีราคา, ดาว rating, สต็อก

**ผลกระทบ:** เสียโอกาส rich snippet ที่ดึงดูด CTR ได้สูงกว่า 30–50%

**วิธีแก้:**
- ใส่ Product Schema ในทุกหน้าสินค้า (ดูตัวอย่าง JSON-LD ในหัวข้อ 1.5)
- ตรวจสอบผล Google Rich Results Test ที่ https://search.google.com/test/rich-results

---

### ปัญหาที่ 6 — ขาด Internal Links ระหว่างสินค้า

**อาการ:** แต่ละหน้าสินค้ายืนอยู่โดดๆ ไม่มีลิงก์ไปสินค้าอื่น

**ผลกระทบ:** Google crawl หน้าสินค้าได้ยาก, link equity กระจายไม่ทั่ว, ผู้ใช้ออกเร็ว (bounce rate สูง)

**วิธีแก้:**
- เพิ่มส่วน "สินค้าที่เกี่ยวข้อง" หรือ "อาจสนใจ" ในทุกหน้าสินค้า
- ใช้ anchor text ที่มีคีย์เวิร์ด ไม่ใช้ "คลิกที่นี่"
- เชื่อม USB เพลงลูกทุ่ง → USB เพลงอีสาน, USB เพลงสตริง ฯลฯ

---

### ปัญหาที่ 7 — เนื้อหาสินค้าบางเกินไป (Thin Content)

**อาการ:** หน้าสินค้ามีแค่ชื่อสินค้า, ราคา, และรูป 1–2 รูป ไม่มีคำอธิบาย

**ผลกระทบ:** Google มองว่าหน้าคุณภาพต่ำ (low-value page) ทำให้อันดับต่ำหรือถูก de-index

**วิธีแก้:**
- เพิ่มคำอธิบายสินค้า 150–300 คำ ที่กล่าวถึง benefit จริง
- เพิ่มส่วน FAQ ("USB นี้ใช้กับรถยี่ห้อไหนได้บ้าง?", "ความจุคือเท่าไหร่?")
- เพิ่มข้อมูลจำเพาะ เช่น ความจุ USB, format ไฟล์เพลง, จำนวนเพลงจริง

---

### ปัญหาที่ 8 — ใช้ชื่อศิลปิน/เพลงที่มีลิขสิทธิ์ใน SEO copy (ปัญหาเฉพาะสินค้านี้)

**อาการ:** Title หรือ Description ระบุชื่อนักร้อง, ค่ายเพลง, หรืออ้างลิขสิทธิ์

**ผลกระทบ:** นอกจากความเสี่ยงทางกฎหมาย ยังทำให้ถูก Google ลงโทษหรือถูก flag ว่า misleading

**วิธีแก้:**
- ใช้คำกลาง: "เพลงฮิต", "เพลงในตำนาน", "เพลงดัง", "เพลงแนวลูกทุ่ง"
- เน้น benefit: "ฟังได้ไม่ต้องเน็ต", "เพลงเยอะคุ้มค่า", "ใช้ได้ทุกเครื่อง"
- ห้ามใช้: ชื่อศิลปิน, ชื่อเพลง, ชื่อค่ายเพลง, คำว่า "ลิขสิทธิ์ถูกต้อง" หรือ "original"

## 4. สรุป Checklist ก่อนเผยแพร่หน้าสินค้า

```
[ ] Title tag: 50–60 ตัวอักษร, มีคีย์เวิร์ดหลัก, มีชื่อแบรนด์
[ ] Meta description: 150–160 ตัวอักษร, มีคีย์เวิร์ด + CTA
[ ] H1: มีเพียง 1 ตัว, มีคีย์เวิร์ด, เน้น benefit
[ ] H2/H3: โครงสร้างสมเหตุสมผล ไม่ข้าม level
[ ] Alt text: ทุกรูปมี alt text พร้อมคีย์เวิร์ด
[ ] URL: สั้น, มีคีย์เวิร์ด, ไม่มีตัวเลขสุ่ม
[ ] Internal links: ลิงก์ไปสินค้าที่เกี่ยวข้องอย่างน้อย 3 รายการ
[ ] Product Schema: ใส่ JSON-LD ครบ
[ ] เนื้อหา: 150 คำขึ้นไป + FAQ อย่างน้อย 3 ข้อ
[ ] Copyright-safe: ไม่มีชื่อศิลปิน/ค่าย/เพลง ไม่เคลมลิขสิทธิ์
```
