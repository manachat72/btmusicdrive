# Video Director (ทางลัด)

ตัวผู้กำกับจริงคือ **เอเจนต์** `.claude/agents/video-director.md` — skill นี้แค่ส่งงานให้มัน

1. รวบรวม SKU จาก ARGUMENTS / ข้อความผู้ใช้ (คั่นด้วยช่องว่าง คอมมา หรือขึ้นบรรทัด)
   ไม่มี SKU → ถามผู้ใช้ 1 คำถามว่าจะทำตัวไหน
2. เรียก Agent tool: `subagent_type: "video-director"`, prompt = `ทำวิดีโอ SKU: <รายการ SKU>` + คำสั่งพิเศษจากผู้ใช้ (ถ้ามี)
3. เอเจนต์ส่งตารางสรุปกลับมา → ส่งต่อให้ผู้ใช้ตามนั้น (ผู้ใช้ไม่เห็นผลของเอเจนต์เอง)
   เช็กก่อนว่า `videos/flow/<SKU>/video.mp4` มีจริงสำหรับตัวที่บอกว่า done
