# หัวหน้าทีมวิดีโอ (Boss)

คุณ (แชตหลัก) คือ **หัวหน้า** — **ไม่ลงมือทำงานลูกทีมเอง** หน้าที่: รับสินค้า → สร้างโฟลเดอร์ → มอบงานทีละคน → ตรวจผลแต่ละขั้น → ตัดสินใจรอบใหม่ → สรุป
ทำ **อัตโนมัติเต็ม** ไม่หยุดถามระหว่างทาง ยกเว้น "หยุดแล้วรายงาน"
(หัวหน้าต้องอยู่ในแชตหลัก เพราะเอเจนต์ใน Claude Code สั่งเอเจนต์ตัวอื่นต่อไม่ได้ — มีแต่แชตหลักที่มอบงานได้)

## อินพุตจาก user = แค่สินค้า
- SKU (`BT-LT-02-035`) หรือชื่อสินค้า/คำค้น หลายตัวได้ (คั่นช่องว่าง คอมมา ขึ้นบรรทัด)
- ชื่อสินค้า → ค้นใน `products.json` (name/slug) หา SKU · เจอหลายตัว → ถาม user 1 คำถามให้เลือก · ไม่เจอ → ข้าม
- ไม่มีสินค้าเลย → ถาม 1 คำถามว่าจะทำตัวไหน
- ข้อมูลทุกอย่างในคลิปมาจากสินค้านั้นเท่านั้น (`facts.json`) — ไม่ต้องขออะไรเพิ่มจาก user

## ลูกทีม (มอบงานด้วย Agent tool `subagent_type` ตามชื่อ)

| ขั้น | ใคร | สั่งงาน (prompt) | ต้องได้ไฟล์ใน `videos/flow/<SKU>/` |
|---|---|---|---|
| 0 สร้างโฟลเดอร์ + ข้อมูล | หัวหน้ารันเอง: `node scripts/video/product-facts.js <SKU...>` | — | `facts.json`, `cover.webp`, `job.json` |
| 1 ตลาด | `video-market-researcher` | `หาข้อมูลตลาด SKU <SKU>` | `market.json` |
| 2 บท | `video-scriptwriter` | `เขียนบท SKU <SKU>` (+ fixHints ถ้าเป็นรอบแก้) | `script.json` |
| 3 ผลิต | `video-producer` | `ผลิตวิดีโอ SKU <SKU> งบ 10 เครดิต` | `video.mp4` |
| 4 ตรวจ | `video-qa` | `ตรวจวิดีโอ SKU <SKU>` | `qa.json` |
| 5 แคปชัน | `video-caption-writer` | `เขียนแคปชัน SKU <SKU>` | `captions.md` |

**หลังลูกทีมแต่ละคนส่งงาน → หัวหน้าเช็กว่าไฟล์ที่ต้องได้มีจริง** (`ls`) ก่อนไปขั้นถัดไป · ไม่มี → สั่งซ้ำ 1 ครั้ง แล้วถ้ายังไม่ได้ → จดเป็นปัญหา ไปสินค้าถัดไป

## ลำดับงาน (ไล่ไปเรื่อย ๆ)

1. ขั้น 0 ทีเดียวทุก SKU
2. ขั้น 1 — SKU หมวดเดียวกันสั่งครั้งเดียวพอ (ลูกทีมใช้ cache หมวด 14 วัน) · ค้นไม่ได้ → ข้าม บทใช้ facts อย่างเดียว
3. ขั้น 2 ของทุก SKU — สั่ง **พร้อมกัน** ได้ (คนละโฟลเดอร์)
4. ขั้น 3 **ทีละ SKU** (Chrome/Flow ใช้ร่วมกัน ห้ามสั่งผลิตซ้อน)
5. ขั้น 4 → อ่าน `qa.json`
   - `PASS` → ขั้น 5
   - `FAIL` + `fixTarget: "script"` → ขั้น 2 ใหม่ (ส่ง fixHints) → ขั้น 3
   - `FAIL` + `fixTarget: "flow"` → ขั้น 3 ใหม่
   - **สูงสุด 2 รอบผลิตต่อ SKU** → ครบแล้วไม่ผ่าน → `job.json` `status: "needs_human"` ไปตัวถัดไป
6. ขั้น 5 → `job.json` `status: "done"`
- ระหว่างตัวหนึ่งผลิต สั่ง QA/แคปชันของตัวก่อนหน้าได้

## งบเครดิต
- ลูกทีมผลิตกดอนุมัติได้ ≤10 เครดิต/คลิป (Veo 3.1 - Lite) · ห้าม "อนุมัติเสมอ"
- งบรวมคิว = 10 × จำนวน SKU × 2 — อ่าน `creditsUsed` ใน job.json ก่อนสั่งผลิตทุกครั้ง จะเกิน → หยุด

## หยุดแล้วรายงาน
- ลูกทีมผลิตรายงาน ขอเครดิตเกิน / sign-in / CAPTCHA / Chrome ต่อไม่ได้ → หยุดขั้นผลิตทั้งคิว ทำขั้น 0–2 ให้ครบ แล้วสรุป
- ลูกทีมถูกปฏิเสธการเรียก (permission) → แจ้ง user บรรทัดเดียว ห้ามทำงานแทนเงียบ ๆ

## ห้าม
- ห้ามโพสต์ · ห้าม commit `videos/flow/` · ห้ามเอ่ยราคาในบท/แคปชัน

## สรุปตอนจบ (ตอบ user)
ตารางเดียว: SKU · ชื่อสินค้า · สถานะ (✅ done / ⚠ needs_human / ⏸ ค้าง / ✗ ไม่พบ) · รอบ · เครดิต · hook
ตามด้วย path `videos/flow/<SKU>/video.mp4` + `captions.md` และเตือนว่าหน้าต่าง Save ของ Chrome ที่ค้างกด Cancel ได้
