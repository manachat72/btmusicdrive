# พรอมรูปสินค้า USB MP3 — แบบหลบลิขสิทธิ์

ใช้กับ gpt-image-2 / Nano Banana / Flux ฯลฯ · คู่กับ skill `usb-mp3-gpt-image-cover`
(safe zone ภาพ AI บนปกจัตุรัส = `[40,130,960,660]` · ล่าง 1/3 ต้องโปร่ง เพราะโดนแถบ BUTTHRRM ทับ · มุมบน 2 ข้างสะอาด)

## 1. หลักหลบลิขสิทธิ์ (อ่านก่อน)

ความเสี่ยงจริงของร้านไม่ใช่ "AI เจนรูป" แต่คือ **รูปที่ทำให้คนเข้าใจว่าเป็นสินค้าลิขสิทธิ์ทางการ** หรือ **ก๊อปงานของคนอื่น**

❌ ห้ามใส่ใน prompt เด็ดขาด
- ชื่อศิลปิน/วงจริง เป็น subject หรือ style — `พุ่มพวง`, `in the style of <วง>`, `<ชื่อวง> album cover`
- ชื่อช่างภาพ/นักวาด/สตูดิโอ เป็น style reference (`in the style of <ชื่อคน>`)
- ใบหน้าเหมือนจริงของคนจริง (นักร้อง/ดารา/พระสงฆ์รูปจริง) — ใช้ **เงา/silhouette/หลังไหล่/เบลอ** แทน
- โลโก้-ยี่ห้อ: Fender, Gibson, Marshall, Sony, Shure, Spotify, Coca-Cola, ธนาคาร, ทีมฟุตบอล
- ตัวการ์ตูน/ตัวละครหนัง/มาสคอต/สติกเกอร์ไลน์
- ปกอัลบั้ม/ปกเทป/โปสเตอร์คอนเสิร์ตจริง ๆ (รวมถึง "ปกเทปยุค 80 ของ <วง>")
- ลายเซ็นศิลปิน, ฟอนต์โลโก้วง, ตราค่ายเพลง (GMM, RS, Sony Music…)
- เอารูปจากเน็ต/ปกจริงไปทำ img2img หรือ reference

✅ ใส่ได้ ปลอดภัย
- ฉาก/ยุค/อารมณ์: ทุ่งนาตอนเย็น, เวทีงานวัด, ห้องอัดยุค 90, รถสองแถว, ตลาดกลางคืน
- เครื่องดนตรี/ของยุค แบบ **unbranded** — เติมคำ `unbranded, no logos, blank headstock` ทุกครั้ง
- เทปคาสเซ็ท/แผ่นเสียง/วิทยุทรานซิสเตอร์/ลำโพงตู้ **ที่ไม่มีตัวหนังสือ**
- คน = เงา ไม่ระบุตัวตน (`anonymous silhouette, face not visible`)
- กราฟิกนามธรรม: soundwave, สายไฟ, แสงเวที, ผ้ากำมะหยี่, เกรนฟิล์ม, ทองปั๊มนูน

ℹ️ ส่วนที่ใช้ได้ตามปกติ (ไม่ใช่งานรูป): **ชื่อเพลง + ชื่อศิลปินในรายชื่อเพลง/ชื่อสินค้า** = ข้อความข้อเท็จจริง บอกว่าในไดรฟ์มีอะไร
พิมพ์ได้ แต่ห้ามจัดให้ดูเหมือนโลโก้/ลายเซ็น/ตราทางการ และห้ามใช้คำ `official`, `ลิขสิทธิ์แท้`, `จัดจำหน่ายโดย…` ถ้าไม่จริง
(ลิขสิทธิ์ "ตัวไฟล์เพลง" เป็นอีกเรื่อง คนละประเด็นกับรูปปก)

## 2. Negative prompt มาตรฐาน (ต่อท้ายทุกครั้ง)

```
NEGATIVE: no real people's faces, no celebrity likeness, no recognizable album cover,
no band logos, no brand names, no trademarks, no readable text of any language,
no watermark, no signature, no record label mark, no cartoon characters,
no busy detail in the bottom third, no clutter in the top-left and top-right corners
```

## 3. Master template

```
ปกสินค้าสำหรับแฟลชไดรฟ์รวมเพลง — ภาพ [SUBJECT: วัตถุ/ฉาก ไม่มีใบหน้าคน],
[PROPS: ของยุคแบบไม่มียี่ห้อ], [LIGHT: ทิศแสง + อารมณ์], โทนสี [PALETTE],
จัดองค์ประกอบ: subject อยู่กลางค่อนบน, ล่างหนึ่งในสามเป็นพื้นมืดเรียบว่าง ๆ,
มุมบนซ้ายและบนขวาโปร่ง, ไม่มีตัวหนังสือในภาพ, [STYLE: cinematic product still life /
painterly poster art], 1:1, ความละเอียดสูง
NEGATIVE: <ชุดข้างบน>
```

กฎเขียน: **บรรยายฉาก อย่าอ้างงาน** — ถ้าอยากได้ฟีล "ปกเทปลูกทุ่งยุค 80" ให้บรรยาย *อะไรทำให้มันเป็นยุค 80* (เกรนฟิล์ม, สีอมส้มซีด, ไฟหลอดไส้, ผ้าซาติน) ไม่ใช่พูดว่า "ปกเทปยุค 80"

## 4. พรอมพร้อมใช้ตามหมวด SKU

**LT · ลูกทุ่ง**
```
ทุ่งนาไทยตอนเย็นแดดร่ม รถเข็นดอกไม้กับพวงมาลัยดาวเรือง ไมโครโฟนโบราณตั้งขาตั้งเหล็ก
ไม่มียี่ห้อ ผ้าซาตินสีชมพูพลิ้วด้านหลัง แสงทองอ่อนจากซ้ายเป็นซุ้มแสงฝุ่นลอย
โทนทอง-ชมพู-เขียวข้าว ฟิล์มเกรนบาง ๆ · subject กลางค่อนบน ล่างหนึ่งในสามเป็นเงามืดเรียบ
มุมบนสองข้างโปร่ง ไม่มีตัวหนังสือ
```

**PC · เพื่อชีวิต**
```
เวทีเล็กกลางแจ้งตอนค่ำ กีตาร์โปร่งเก่าพาดเก้าอี้ไม้ หัวกีตาร์เปล่าไม่มีโลโก้
ขวดน้ำสังกะสี ลำโพงตู้ผ้าเก่า ๆ ไม่มีตัวอักษร ควันจาง ๆ แสงไฟหลอดไส้เหลืองแขวนสายเดียว
โทนน้ำตาลไหม้-ส้มอิฐ-เทาควัน ภาพแนวสารคดี · ล่างหนึ่งในสามมืดเรียบ มุมบนโปร่ง ไม่มีตัวหนังสือ
```

**ST · สตริง / ROCK**
```
ห้องซ้อมดนตรีมืด ปิ๊กกีตาร์แบบเรียบไม่มียี่ห้อวางบนตู้แอมป์หน้าตะแกรงเปล่า สายแจ็คขดบนพื้นปูน
ลำแสงเวทีสีส้ม-แดงเฉียงจากมุมซ้ายบน ฝุ่นลอยในลำแสง โทนถ่าน-ส้มอำพัน-แดงเลือดหมู
คอนทราสต์สูงแบบภาพโฆษณา · subject กลางค่อนขวา ล่างหนึ่งในสามมืดสนิทเรียบ มุมบนสองข้างโปร่ง
ไม่มีตัวหนังสือ ไม่มีโลโก้วง
```

**LK · ลูกกรุง**
```
โต๊ะไม้ขัดเงา เครื่องเล่นแผ่นเสียงทรงคลาสสิกไม่มียี่ห้อ ไม่มีฉลากบนแผ่น แจกันดอกกุหลาบขาว
ม่านกำมะหยี่สีไวน์ด้านหลัง แสงนุ่มจากหน้าต่างด้านขวา โทนครีม-ทองซีด-แดงไวน์ ฟีลภาพถ่ายเก่าอบอุ่น
· ล่างหนึ่งในสามเป็นผ้าคลุมมืดเรียบ มุมบนโปร่ง ไม่มีตัวหนังสือ
```

**TA · เพลงใต้**
```
ท่าเรือประมงตอนเช้า เรือหัวโทงทาสีสดจอดเรียง ทะเลเรียบสะท้อนแสงส้ม ฉิ่งกับกลองใบเล็กวางบนเสื่อ
ไม่มีตัวอักษรบนเรือ โทนฟ้าเทอร์ควอยซ์-ส้มอาทิตย์-ขาวทราย ภาพสว่างสดใส
· subject กลางค่อนบน ล่างหนึ่งในสามเป็นน้ำเข้มเรียบ มุมบนโปร่ง ไม่มีตัวหนังสือ
```

**IN · สากล**
```
สตูดิโอมืดสไตล์วินเทจ ไมค์คอนเดนเซอร์ทรงคลาสสิกไม่มียี่ห้อในกรอบกันสะเทือน หูฟังคาดบนขาตั้ง
แผงปรับเสียงเบลอด้านหลังไม่มีตัวหนังสือ แสงสปอตขาวนวลจากบนซ้าย โทนน้ำเงินเข้ม-เงิน-ขาวนวล
มินิมอล พรีเมียม · ล่างหนึ่งในสามดำเรียบ มุมบนสองข้างโปร่ง ไม่มีตัวหนังสือ
```

**DZ · แดนซ์**
```
ฟลอร์เต้นนามธรรม ลำแสงเลเซอร์สีชมพู-ฟ้า-ม่วงตัดกัน ละอองหมอก เงาคนเต้นไม่เห็นหน้าอยู่ไกล ๆ
กราฟิกคลื่นเสียงเรืองแสง ไม่มีหน้าจอที่มีตัวหนังสือ โทนนีออนแมเจนตา-ไซแอน-ม่วง คอนทราสต์จัด
· กลุ่มแสงอยู่ครึ่งบน ล่างหนึ่งในสามมืดสนิท มุมบนโปร่ง ไม่มีตัวหนังสือ ไม่มีโลโก้คลับ
```

**DM · ธรรมะ**
```
ศาลาไม้เงียบตอนเช้า บาตรพระวางบนผ้าเหลืองพับ ดอกบัวตูมในขันน้ำ ควันธูปบางลอยขึ้น
แสงเช้าส่องเฉียงผ่านช่องหน้าต่างเป็นลำสว่าง ไม่มีพระ ไม่มีใบหน้าคน ไม่มีพระพุทธรูปที่จำได้ว่าองค์ไหน
โทนทองอ่อน-น้ำตาลไม้-ขาวนวล สงบ สะอาด · ล่างหนึ่งในสามเป็นพื้นไม้มืดเรียบ มุมบนโปร่ง ไม่มีตัวหนังสือ
```

**RD · วิทยุ**
```
วิทยุทรานซิสเตอร์เก่าตัวเดียวบนโต๊ะไม้ หน้าปัดเปล่าไม่มีตัวเลขตัวหนังสือ เสาอากาศยืด สายไฟถัก
ฉากหลังผนังปูนเปลือยเบลอ แสงเหลืองอุ่นจากขวาเป็นเงายาว ฝุ่นลอย โทนน้ำตาล-ครีม-ทองเหลือง
ฟีลภาพถ่ายฟิล์มเก่า · subject กลาง ล่างหนึ่งในสามเป็นโต๊ะมืดเรียบ มุมบนโปร่ง ไม่มีตัวหนังสือ
```

**AC · อุปกรณ์เสริม**
```
ภาพนิ่งสินค้าบนพื้นหลังเทาไล่เฉด แฟลชไดรฟ์โลหะเปล่าไม่มีโลโก้กับสายคล้องวางเป็นองค์ประกอบสะอาด
แสงซอฟต์บ็อกซ์จากบนซ้าย เงานุ่มสั้น สะท้อนเงาบนพื้นเล็กน้อย โทนเทา-เงิน-ส้มอำพันจุดเดียว
มินิมอลแบบแคตตาล็อก · วัตถุกลางค่อนบน ล่างหนึ่งในสามเทาเรียบ มุมบนโปร่ง ไม่มีตัวหนังสือ
```

## 6. เช็คก่อนส่งขึ้นเว็บ/แพลตฟอร์ม

1. ซูม 100% หาตัวหนังสือมั่ว/โลโก้มั่วที่ AI แถมมา → มีให้ inpaint ทับหรือเจนใหม่
2. มีใบหน้าคนที่ดู "เหมือนใคร" ไหม → เอาออก
3. รูปรวมดูเหมือนปกอัลบั้มจริงชุดไหนไหม → เปลี่ยนองค์ประกอบ
4. Google reverse image search รูปที่จะใช้ 1 รอบ
5. อย่าใส่คำโฆษณาว่าเป็นสินค้าลิขสิทธิ์ทางการ ถ้าไม่ได้เป็น

> หมายเหตุ: เอกสารนี้เป็นแนวปฏิบัติลดความเสี่ยงสำหรับงานออกแบบ ไม่ใช่คำแนะนำทางกฎหมาย
