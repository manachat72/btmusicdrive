# BT Music Drive Content Studio

เครื่องมือส่วนตัวในโปรเจกต์ร้าน อ่านสินค้าจาก `products.json` และไม่แก้ข้อมูลสินค้า

## เปิดใช้งาน

รัน `npm run content:studio` จากโฟลเดอร์โปรเจกต์ แล้วเปิด http://127.0.0.1:4781/

หากพอร์ตไม่ว่าง ตั้ง `$env:CONTENT_STUDIO_PORT = '4782'` ใน PowerShell ก่อนรันคำสั่งเดิม
ใช้เบราว์เซอร์และพอร์ตเดิมเพื่อเข้าถึงประวัติที่บันทึกไว้

## ขั้นตอน

1. เลือกสินค้า ตรวจชื่อ จุดขาย ราคา และรูปที่ต้องการแนบ เลือกแนวคลิป 6 แบบ สัดส่วน เสียง และความยาว
2. เลือกหนึ่งใน 3 ไอเดีย แล้วแก้พรอมต์ บทพูด และข้อความสำหรับตัดต่อทีละฉาก คัดลอกไป Flow และแนบภาพอ้างอิงเอง
3. หลังได้คลิป แนบไฟล์เพื่อดูในเครื่อง หรือกรอกสรุปวิดีโอจริง เลือกช่องทางและตรวจข้อมูลอีกครั้งเพื่อสร้างชุดโพสต์
4. แก้ข้อความแยกช่องทาง บันทึกสถานะร่าง / พร้อมโพสต์ / โพสต์แล้ว พร้อมลิงก์โพสต์
5. กดบันทึกงาน และสำรอง JSON เพื่อนำเข้าใหม่หรือย้ายเครื่อง ดาวน์โหลด TXT เพื่อใช้พรอมต์และข้อความนอกเครื่องมือ

## AI ในเครื่อง

เลือก AI ในเครื่อง (ค่าเริ่มต้น) เพื่อคิดไอเดีย 3 แบบ เขียนฉากใหม่ แก้เฉพาะฉาก และเขียนโพสต์แยกแพลตฟอร์มผ่าน Ollama ที่ `127.0.0.1:11434` ด้วยโมเดล `gpt-oss:20b` ที่ติดตั้งไว้ ไม่มี API key และไม่เรียกบริการ AI ภายนอก

เปิด Ollama ก่อนใช้ ปุ่มตรวจการเชื่อมต่อแสดงสถานะจริง เปลี่ยนชื่อโมเดล local ได้ด้วย `CONTENT_STUDIO_MODEL` ก่อนเริ่มเซิร์ฟเวอร์ ตัวเลือกแม่แบบยังใช้ได้เมื่อไม่ต้องการใช้ AI (ระบบไม่สลับเป็นแม่แบบเองเมื่อ AI ล้มเหลว)

ช่องบอก AI เพิ่มเติมใช้ได้ทั้งการคิดไอเดีย สร้างฉาก แก้เฉพาะฉาก และเขียนโพสต์ เช่น “ขายเนียนขึ้น พูดเหมือนเพื่อนแนะนำ” ระหว่างคิดจะล็อกช่องแก้ไขและแสดงเวลารอ สามารถยกเลิกได้ งานเดิมจะไม่ถูกแทนที่หากสร้างไม่สำเร็จ

GPT OSS ในเครื่องนี้รับข้อความ ไม่วิเคราะห์รูปหรือวิดีโอ ภาพอ้างอิงเก็บไว้เพื่อแนบใน Flow ตรวจข้อมูลสินค้าและภาษาไทยก่อนใช้ผลลัพธ์

## ขอบเขต

### API แบบเสียเงิน (สำรอง)

เลือก OpenAI API กรอกคีย์ เลือก GPT-4.1 mini หรือ GPT-4.1 แล้วกดเชื่อมต่อ คีย์เก็บเฉพาะ RAM ของเซิร์ฟเวอร์ ไม่อยู่ใน localStorage หรือไฟล์สำรอง ปุ่มเชื่อมต่อเพียงตั้งค่าคีย์ สิทธิ์จริงจะตรวจเมื่อสร้างครั้งแรก กดตัดการเชื่อมต่อหรือปิดเซิร์ฟเวอร์เพื่อล้างคีย์

เมื่อกดสร้างในโหมด OpenAI จะส่งข้อมูลข้อความของงานไป `api.openai.com` และมีค่า API ตามบัญชีของผู้ใช้ ไม่ใช่โควตาสมาชิก ChatGPT ระบบไม่เปลี่ยนไปใช้ API เสียเงินอัตโนมัติ และหน้าเว็บที่เปิดใหม่กลับไปเลือก AI ในเครื่องเป็นค่าเริ่มต้น การทดสอบอัตโนมัติใช้ OpenAI จำลอง ไม่ใช้เครดิตจริง

- สร้างข้อความด้วย AI ในเครื่อง หรือแม่แบบตามที่เลือก ไม่เรียก API ของ Google Flow และไม่สร้างวิดีโอเอง
- ไม่อัปโหลดวิดีโอ ไม่วิเคราะห์วิดีโออัตโนมัติ และไม่เผยแพร่โพสต์เอง
- ข้อมูลสินค้าเป็น snapshot จากไฟล์ในเครื่อง ไม่ใช่ API ราคาสด ตรวจราคาก่อนใช้
- ประวัติและการตั้งค่าเก็บใน localStorage ของ origin นี้ ไม่ซิงก์ข้ามเครื่อง การล้างข้อมูลเบราว์เซอร์จะลบงาน จึงควรสำรอง JSON
- ไฟล์วิดีโอไม่รวมใน JSON เก็บเฉพาะชื่อไฟล์ ต้องแนบวิดีโออีกครั้งเมื่อเปิดงานเดิม
- ปุ่มสร้างใหม่แทนที่ข้อความที่แก้ไว้และถามก่อนทำ การเปลี่ยนข้อมูลต้นทางจะทำเครื่องหมายผลลัพธ์เก่าว่าต้องสร้างใหม่
- หน้าต่างนี้ใช้เฉพาะในเครื่อง (127.0.0.1) ไม่มี admin password หรือข้อมูลบัญชี และไม่ได้เพิ่มในหน้าเว็บ production ของ Vercel

## โครงสร้าง

- `scripts/content-studio.js`: เซิร์ฟเวอร์ local แบบ allowlist อ่านเฉพาะสินค้าและไฟล์เครื่องมือ ไม่เปิดโฟลเดอร์โปรเจกต์ทั้งก้อน
- `content-studio/core.js`: ตัวสร้างฉาก/โพสต์ และตรวจ schema ของไฟล์สำรอง แยกจาก UI เพื่อเปลี่ยนมาใช้ผู้ให้บริการ AI ได้ภายหลัง
- `content-studio/app.js`: จัดการ UI บันทึกงาน นำเข้า/ส่งออก และตัวอย่างวิดีโอ
- `content-studio/style.css`: สไตล์เฉพาะเครื่องมือ ไม่โหลดบนหน้าร้าน ไม่มี dependency หรือสคริปต์ภายนอกเพิ่ม

ยังควรอยู่ในโปรเจกต์เดียวกัน เพราะใช้ข้อมูลสินค้าร่วมกัน แยกเป็นแอปใหม่เมื่อจำเป็นต้องมีผู้ใช้หลายร้านหรือจัดการสิทธิ์และการเผยแพร่ของตัวเอง

ตรวจด้วย `npm run content:test` และ `npm run build` ตามกฎของโปรเจกต์
